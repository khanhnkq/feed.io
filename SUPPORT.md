# Support

Use the repository issue templates for reproducible bugs and focused feature proposals. Use discussions for setup help, architecture questions and general ideas when discussions are enabled.

Before asking for help:

1. Read the README and current limitations.
2. Search existing issues.
3. Run `make verify` and capture the failing command.
4. Include OS, Docker, Node, pnpm, Python and uv versions.
5. Redact secrets and private media metadata.

Feed.io is a community project and currently has no guaranteed response time or commercial support channel.
