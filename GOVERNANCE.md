# Governance

Feed.io currently uses a maintainer-led model.

## Decision process

- Small implementation decisions are reviewed in pull requests.
- Product changes start as issues with acceptance criteria.
- Architectural or operational changes require an ADR.
- Security reports remain private until remediation is available.
- When consensus is not reached, the maintainer records the decision and trade-offs in the issue or ADR.

## Roles

- **Contributor:** anyone submitting issues, documentation, designs or code.
- **Reviewer:** a trusted contributor who regularly reviews within an area.
- **Maintainer:** owns releases, repository administration, security coordination and final architectural decisions.

Review and maintainer access is granted based on sustained, constructive contribution rather than employment or volume alone.
